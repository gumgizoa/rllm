## 0. 요약

- **새 평가기의 총점도 같은 방향, 작은 폭.** score 0.545 → 0.862 (+0.32). 08의 ifeval compliance는 0.343 → 0.783 (+0.44)이었다. 해결률은 같다(0.515 → 0.519).
- **범주별로는 금지 행동(R)만 안 움직였다.** 절차 P +0.37, 형식 F +0.42, 실행 E +0.29, 단계 간 일관성 C +0.48, 보고 정확성 A +0.37, 금지 R −0.01(두 모델 다 0.90).

| T-OR1 순서 사슬 | 0.31 → 0.71 | 0.82 → 0.97 | ifeval은 사슬 전체 1개 항목, 새 평가기는 단계별 13 항목 |
| T-TR2 계획 이행 | 0.40 → 0.75 | 0.13 → 0.38 | 다른 인스턴스 (계획 대상 vs 실제 변경 / build 명령 실행) |
| T-RD6 재독 금지 | 0.60 → 0.59 | 0.41 → 0.46 | 새 평가기는 같은 명령 안의 read-back도 셈 |
| T-AW4 지연 실행 | 0.55 → 0.66 | 0.59 → 0.77 | 비슷 |
| T-AW2 수정 전 baseline | 0.33 → 0.42 | 0.54 → 0.59 | 새 평가기는 편집 시점을 모르면 판정 안 함 |
| T-FM2 골격 | 0.67 → 0.95 | 0.74 → 0.94 | 비슷 |

템플릿은 판정 로직의 **종류**이고 엄격함은 인스턴스마다 다르다. 두 평가기 사이에서 템플릿 이름으로 수치를 비교하면 안 되고, 각 평가기 안에서의 Δ 방향만 비교할 수 있다. 방향은 T-AW6(ifeval +0.09, 새 −0.02)과 T-WD2(+0.39, −0.02)를 빼면 일치한다.

## 7. 해석과 한계

**얻은 것.**

- 다른 설계의 평가기로 재도 결론이 같다. 학습은 절차·형식·일관성·보고 정확성을 올리고, 금지 행동은 원래 지켜졌으며, 해결률은 그대로다.
- 충돌 층에서 떨어진 항목이 없다는 것도 같다. 지연 실행은 더 지키게 됐고 재독 금지는 두 모델 다 절반이다.
- 정보 있는 L2 method 7개 중 6개가 올랐다(재현 스크립트 마지막 수정 뒤 실행 +0.26, 출력 옵션 +0.15, 이슈에 없는 NFR +0.11, 재현 스크립트 쓰기 시점 +0.08, 05 변경 파일 일치 +0.05, 04 미공개 변경 없음 +0.04). baseline 실행 뒤 기록만 평평하다(+0.02). n이 작은 build 명령 실행(H1a/H1b)도 +0.3 방향이다.

**못 얻은 것 / 주의.**

- **L2 층 평균은 이 평가기에서 쓸 수 없다.** 천장 항목이 평균을 고정한다. 층을 쓰려면 정보 있는 method만으로 다시 묶거나, 템플릿 단위로 보고해야 한다. 08에서 말한 "k는 템플릿 수이고 천장은 빠진다"가 그대로 나타났다. 실질 k: 충돌 2, L2-중간 3, L2-먼 2.
- **층 라벨은 초안이다.** method마다 템플릿과 층을 제가 붙였고 검토되지 않았다. 갈릴 수 있는 판단: T-RF3을 L2-중간으로 둔 것(step27은 그 항목을 보상한 옛 rubric으로 학습했으므로 이 checkpoint에는 L1이 맞다. 옮겨도 T-RF3은 0.92~0.94로 평평해 층 수치는 거의 안 변한다), T-OR2 네 method 중 셋을 L1로 둔 것, 관찰 후 기록을 L2-중간으로 둔 것(엄격히는 L2-먼), 이슈 충실성 F3만 L2-중간.
- **judge 26개는 채점되지 않았다.** Q 범주는 코드 atom 4개만 들어갔다. judge를 붙이면 Q 범주와 J 층이 생기고 총점도 바뀐다.
- **"도달"은 B1(산출물 수집) 통과 또는 그 단계 문서 읽음으로 정의했다.** 08과 같은 기준이다.
- 부분 점수(0.5)가 통과율 평균에 그대로 들어간다. 표의 "통과율"은 정확히는 평균 점수다.
- T-TR1b(키별 대응)가 없어서 08의 L2-먼 근거였던 항목을 이 평가기로는 확인할 수 없다. 새 평가기에 method를 하나 추가하면 된다(S3 Requirement Coverage의 `Rn: Step k`와 04 Plan Execution의 `Step n [Rx]` 키별 대조).
