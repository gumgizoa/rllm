Solve this task the way you normally would, then write the change up with Agent OS's four command
documents (shape-spec, write-spec, create-tasks, implement-tasks), which you carry out yourself, in that
order, once the change is made and tested, within this one session.

Before you look at the repository, open /agent-os/overview.md; that is your first action. /agent-os
hangs directly off the root directory /, apart from the repository you work in, so it is not to be found
inside the repository. overview.md gives the path of each command document, the spec folder the commands
write to, and the point at which you call finish.
