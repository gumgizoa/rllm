Solve this task the way you normally would, then write the verification report that Agent OS describes,
within this one session.

Before you look at the repository, open /agent-os/overview.md; that is your first action. /agent-os
hangs directly off the root directory /, apart from the repository you work in, so it is not to be found
inside the repository. overview.md gives the folder the report goes to, what the report holds, and the
point at which you call finish.
