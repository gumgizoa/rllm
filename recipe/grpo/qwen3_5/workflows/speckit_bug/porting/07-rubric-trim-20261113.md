## 4. 생성물 처리 방식

- 이 기계에 claude CLI가 없어 `generator build`로 재생성하지 않고 rubric.yaml/.md/.lock을 직접 편집함. lock의 `config.sha256`, `sources.*`, `rubric_sha256`은 재계산함.
- `python -m recipe.grpo.qwen3_5.workflow_rubric.generator check speckit_bug --llm none`: 0 problem.
- 런타임(`RubricEvaluation`)은 lock을 검사하지 않으므로 학습·eval에 바로 쓸 수 있음.
- 문서 해시가 바뀌어 `artifacts.workflow.sha256`이 달라짐. 이전 run과 `rescore_compliance.py --compare`하면 version_mismatch가 뜨는데 정상임.
- 나중에 DGX09에서 `build`로 재생성하면 LLM 추출 항목이 일부 달라질 수 있음.
